# DVS Planning v33

Aggiornamento della v32. Su iPhone le card mostrano programma, orario compatto, solo cognome, note rosse e, quando presenti, VARIABILE, DOPPIA POSTAZIONE, GRAFICA, COLOR e SOUND. Le indicazioni possono comparire insieme anche senza note.

Griglia panoramica, zoom e colonne adattate ai cognomi conservati. Layout e comandi Mac/iPad invariati; numero versione aggiornato ovunque.

Per aggiornare il sito di test usare i file di questa cartella mantenendo la propria configurazione. Non eseguire gli script SQL per questo aggiornamento: non sono richieste modifiche al database. La configurazione Supabase inclusa è quella precedente; le modifiche ai turni possono quindi interessare il database condiviso.

Sono conservati assets, configurazione, script database e documentazione di installazione; downloads/DVS_Backup_Agent.pkg serve al download del backup dall’app. Eliminati il vecchio changelog e le istruzioni della precedente prova. Nessuna pubblicazione automatica.
